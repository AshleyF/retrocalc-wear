# RetroRPN

RetroRPN is a reverse Polish notation calculator, made by Ashley Nathan Feniello. It is a four-level stack, scientific functions, and four programmable functions, in the spirit of the classic Hewlett-Packard machines.

The Apple Watch app is in [apple](apple). The original Android Wear app is in [wear](wear).

Questions and bugs go to [GitHub issues](https://github.com/ashleyf/retrocalc-wear/issues) or retrorpn@briefrobotics.com. The [support page](apple/support.md) and the [privacy policy](apple/privacy-policy.md) are there too.
